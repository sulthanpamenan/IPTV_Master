## ✨ Key Features

- **Multi-Source Aggregation:** Combines multiple live TV feeds, regional channels, sports networks, and video-on-demand libraries into one unified hub.
- **Automated Stream Maintenance:** Background automation refreshes session tokens regularly to ensure high stream availability and prevent broken links.
- **Rich EPG Metadata:** Detailed program schedules, category tags, episode details, and high-resolution channel logos (`tvg-logo`).
- **TMDB Integration:** VOD content features advanced TMDB metadata (`tvg-tmdb`) mapping for posters, descriptions, and cast information.
- **Universal Compatibility:** Standardized M3U/M3U8 and XMLTV formats fully compatible with all modern media centers and IPTV apps.

## 🚀 Quick Setup Guide

1. Open your IPTV application (e.g., **TiviMate**, **OTT Navigator**, or **Televizo**).
2. Add a new **M3U Playlist** and paste the desired playlist URL.
3. Add the corresponding **EPG/Teleguide URL** to enable program schedules.
4. Refresh your provider to load channels and metadata.
