# 📺 IPTV Master Playlist

A curated, self-maintained M3U playlist collection featuring various live TV channels, custom channel logos, and streaming links. Built for seamless playback across IPTV clients like **OTT Navigator**, **TiviMate**, **IPTV Smarters**, and **Kodi**.

---

## 🚀 Quick Start / URLs

Import this raw playlist URL directly into your preferred IPTV client:

| Resource | URL |
| :--- | :--- |
| **Playlist (M3U)** | `[https://raw.githubusercontent.com/sulthanpamenan/IPTV_Master/main/playlist.m3u8](https://sulthanpamenan.github.io/IPTV_Master/playlist.m3u8)` |

---

## 🛠️ Repository Contents

- **`playlist.m3u8`**: Main IPTV playlist file containing stream URLs and metadata tags.
- **`Logos/`**: Dedicated directory hosting custom channel logos and icons.
- **`WebGrabPlus-Master/`**: EPG configuration setup for program guide generation.

---

## 📱 How to Use in OTT Navigator / IPTV Players

1. Open your IPTV Player (e.g., **OTT Navigator**, **TiviMate**).
2. Add a new playlist source using **M3U / URL**.
3. Paste the following URL:
   https://raw.githubusercontent.com/sulthanpamenan/IPTV_Master/main/playlist.m3u8
4. Save and reload the playlist to start streaming!
